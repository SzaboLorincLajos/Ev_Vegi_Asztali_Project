# Év Végi Asztali Projekt – Szöveges Kalandjáték

## Leírás
Egy szöveges alapú kalandjáték Java nyelven. A játékos egy várkastélyban barangol,
ellenfelelekkel harcol, ládákat nyit ki és megpróbál túlélni.

## Indítás
Fordítsd le a projektet IntelliJ IDEA-ban, majd futtasd a `Main.java` fájlt.

## Parancsok
- `go north/south/east/west` – mozgás
- `open chest` – láda kinyitása
- `look` – szoba megnézése
- `status` – karakter adatok
- `save` – játék mentése
- `help` – parancsok listája
- `exit` – kilépés

## Kasztok
- **harcos** – több életerő, erősebb fizikai támadás
- **magus** – több mana, varázslat képesség
